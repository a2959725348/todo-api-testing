## 环境与方法

Windows 本地环境，复用项目虚拟环境中的固定依赖；接口指向独立服务 http://localhost:51984。UI 使用 Chrome 无头模式，窗口 1280×900。测试服务仅在隔离测试期间运行，结束后关闭。会话级重置只作用于该隔离服务。

执行命令：

```powershell
$env:BASE_URL = 'http://localhost:51984'
pytest -c pytest.ini -o addopts= -p no:cacheprovider -q --junitxml=reports/api.xml
pytest -c ui.ini -o addopts= -p no:cacheprovider -q --junitxml=reports/ui.xml
```

上述命令要求先在该端口启动独立服务；一般复现按仓库 README 执行 `pytest` 和 `pytest -c ui.ini` 即可使用默认的自动托管服务。
